labyrinth-first-components: at the first login after installing, installs the optional parts chosen in the installer that
the installer medium did not carry (Sarina, Heimdall...). The installer leaves their component ids in
/var/lib/labyrinth/first-login-components.json, owned by the new user; this runs at sign-in and whenever the computer comes
online (labyrinth-first-components.service, started by graphical-session.target and Yggdrasil's yggdrasil-online.target), says
what it is doing in notifications, and installs them with labyrinth-apps through Agora's password box (they are built or
fetched, so they need the internet). When everything is in, the file is removed; when an install fails it is not tried again
until the next login, and Agora can install them at any time.
